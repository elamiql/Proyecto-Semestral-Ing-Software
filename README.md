# Proyecto Semestral Ingenieria de Software

Visión del Producto

Crear un sistema  que permita a la comunidad del campus reportar objetos perdidos, encontrados y ver los reportes en tiempo real. Un encargado podrá revisar esas coincidencias y gestionar la recuperación de los objetos. El objetivo es reducir pérdidas y hacer más eficiente y confiable el proceso.


Visión sprint 1

En este sprint se trabajó en las funcionalidades generales de la plataforma, incluyendo el registro de objetos perdidos y encontrados, así como la visualización de los reportes correspondientes.


Visión Sprint 2 

En este sprint se trabajó en dos objetivos principales.
El primero consistió en mejorar el apartado visual de la aplicación para ofrecer una experiencia más clara, moderna y alineada con las necesidades del cliente.
El segundo objetivo fue completar las funcionalidades de la plataforma, lo que incluyó la creación de dos interfaces diferenciadas para separar los roles de administrador y usuario general. Además, se implementó un sistema de inicio de sesión que refuerza la seguridad permitiendo el acceso únicamente a usuarios con correo institucional UdeC.
